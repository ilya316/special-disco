# Книга заклинаний

Мобильное веб-приложение (PWA) для D&D 5e: заклинания персонажа с [dnd.su](https://dnd.su/spells/) (2014) и [next.dnd.su](https://next.dnd.su/spells/) (2024), трекер хитов, ячеек заклинаний и ресурсов. Работает офлайн, все данные хранятся на телефоне.

## Возможности
- **Заклинания**: добавление по ссылке, вставкой скопированного текста или вручную; поиск, фильтр по уровню, отметка «подготовлено» (★). «Сотворить» тратит ячейку, бесплатное использование (с лимитом или без) или ничего.
- **Трекер**: хиты (урон сначала снимает временные), спасброски от смерти, кости хитов с броском (+ мод. ТЕЛ), ячейки 1–9 и ячейки колдуна (с автозаполнением по уровню), свои ресурсы, короткий и длинный отдых.
- **Лист**: характеристики, спасброски, навыки с владением и компетентностью, бонус мастерства, грузоподъёмность, прыжки в длину и высоту.
- **Вещи**: монеты, предметы с количеством, весом и ценой, итоговый груз и стоимость.
- **Заметки**: текст с форматированием (жирный, курсив, подчёркнутый, зачёркнутый, заголовки, списки, цитаты); вставка из сайтов и документов сохраняет форматирование.
- **Персонажи**: несколько персонажей (нажмите на имя в шапке), экспорт/импорт резервной копии в JSON.
- **Синхронизация**: персонажи хранятся в облаке (Cloudflare D1) и доступны на всех устройствах по коду синхронизации.
- **Android**: в Chrome на странице заклинания «Поделиться» → «Заклинания» — ссылка или выделенный текст сразу попадает в приложение.

## Публикация на GitHub Pages (бесплатно, один раз)
1. Зарегистрируйтесь на github.com и создайте публичный репозиторий, например `spellbook`.
2. «Add file → Upload files» — перетащите **всё содержимое** этой папки (index.html, css, js, icons, manifest.webmanifest, sw.js). Commit.
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет по адресу `https://<ваш-логин>.github.io/spellbook/`.

## Установка на телефон
- **Android (Chrome)**: откройте адрес → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **iPhone (Safari)**: откройте адрес → «Поделиться» → «На экран „Домой“».

Дальше приложение запускается с иконки и работает без интернета (интернет нужен только для загрузки заклинания по ссылке).

После обновления файлов в репозитории увеличьте `VERSION` в `sw.js`.

## Если загрузка по ссылке не работает
Браузер не позволяет сайту читать страницы dnd.su напрямую, поэтому используются публичные прокси — они иногда недоступны. Варианты:
- Вкладка «Вставить текст»: выделите на странице заклинания текст от названия до конца описания, скопируйте и вставьте.
- Свой бесплатный прокси на Cloudflare Workers: dash.cloudflare.com → Workers & Pages → Create Worker → вставьте код из `tools/cf-worker.js` → Deploy. В приложении: Персонаж → Настройки → «Свой прокси» = `https://<имя>.<аккаунт>.workers.dev/?url={url}`.

## Запуск на компьютере
```
python -m http.server 8000
```
и открыть http://localhost:8000.

## Синхронизация между устройствами
Нажмите на имя персонажа в шапке → «Синхронизация» → «Включить». Появится код вида `xxxx-xxxx-xxxx-xxxx-xxxx`.
На другом устройстве: тот же экран → «У меня уже есть код» → ввести код. Дальше изменения сами отправляются в облако
через пару секунд и подтягиваются при открытии приложения (и раз в 30 секунд, пока оно открыто).
Точка в шапке: зелёная — всё сохранено, синяя — идёт отправка, красная — ошибка (например, нет интернета; изменения уйдут позже).

Данные лежат в базе D1 того же воркера Cloudflare (`tools/cf-worker.js`, привязка `DB` в `wrangler.jsonc`).
Код — единственный ключ к данным, не публикуйте его.

## Резервная копия
Данные живут в хранилище браузера. Очистка данных браузера их удалит — периодически делайте «Экспорт» во вкладке «Персонаж».
